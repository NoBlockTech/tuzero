тузиро - простенький vpn протокол, для обхода региональных блокировок в россии
полностью написанный с нуля, не базируясь на других протоколах

**если вы ищете vpn клиент для tuzero - используйте [tucat](https://github.com/noblocktech/tucat)** ^._.^

**настройка на *сервере*: [tudog](https://github.com/noblocktech/tudog)** ▼•ᴥ•▼

usage:
`tuzero -c config.json`
